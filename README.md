# 동글동글 국어 구조대

초등학교 3학년 창의적 개발물 프로젝트를 위해 만든 국어 학습 웹게임입니다. 국어 퀴즈를 풀며 오염된 세 나라를 깨끗하게 만들고, 잡혀간 가족을 구한 뒤 나무나라와 화해하는 이야기입니다.

## 게임 구성

1. **초성나라** — 초성을 보고 낱말을 맞혀 매연을 친환경 필터로 정화합니다.
2. **속담나라** — 뜻에 알맞은 속담을 골라 바닷속 쓰레기를 치웁니다.
3. **용암 끝말잇기** — 앞말의 마지막 글자로 시작하는 말을 골라 용암을 식힙니다.

각 스테이지에는 초급·중급·고급 난이도가 있습니다. **한 나라의 세 난이도를 모두 완료해야 다음 나라가 열립니다.** 난이도에 따라 힌트 횟수와 제한 시간이 달라지며, 높은 난이도일수록 새싹을 더 많이 얻습니다. 모든 문항은 초등학교 3학년이 이해하고 풀 수 있는 낱말과 속담으로 구성했으며, 틀린 문제는 정답을 찾을 때까지 다시 도전할 수 있습니다.

## 실행 방법

설치가 필요하지 않습니다. `index.html`을 웹브라우저로 열면 바로 실행됩니다.

로컬 웹서버로 실행하려면 다음 명령을 사용할 수 있습니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다.

## GitHub Pages 공개 방법

저장소의 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`를 선택하고, `main` 브랜치의 `/ (root)` 폴더를 지정하면 웹게임 주소를 만들 수 있습니다.

## 사용 기술

- HTML5
- CSS3 반응형 디자인 및 애니메이션
- Vanilla JavaScript
- 게임 전용 AI 일러스트 4종(WebP 최적화)
- 브라우저 `localStorage`를 이용한 진행 기록 저장
- Web Audio API를 이용한 간단한 효과음

## 교육적 특징

- 초등학교 3학년이 이해하기 쉬운 낱말과 설명
- 오답이어도 다시 생각하고 도전하는 방식
- 키보드 조작, 큰 글자와 버튼, 화면 읽기 보조 문구 지원
- 국어 학습과 환경 보호 메시지를 하나의 이야기로 연결
- 동글동글한 캐릭터, 스테이지 미리보기, 문제 진행 발자국 등 초등학교 3학년 눈높이의 UI
